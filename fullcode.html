How it works:

Color ID is the pixel's hue angle. BRI and SAT are calculated independently for every pixel.
Color ID 001–360
Hue angle in degrees, converted to a whole number from 001 to 360. Grayscale pixels are assigned 001 because they have no defined hue.
Pixel count 172,800
480 × 360 pixels, read from left to right and top to bottom.
Number format 3 digits
Color ID uses 001–360. BRI and SAT use 000–100. All values are separated by hyphens.
